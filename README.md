# Currículo web – Luiza Borges Lopes

Página única em HTML5, CSS3 e Bootstrap 5, no mesmo visual do portfólio (tema roxo, azul e luas).

- `index.html`: conteúdo do currículo (Objetivo, Experiência, Formação e cursos, Habilidades, Contato)
- `css/style.css`: estilos, incluindo versão própria para impressão
- `assets/foto-luiza.jpg`: foto

O botão **Imprimir / salvar PDF** abre a impressão do navegador com um layout limpo, em fundo branco, para gerar o PDF.
Para publicar: GitHub Pages (Settings > Pages > Deploy from a branch > root).
